# MyPortfolio Website

A professional and modern portfolio website built with HTML, CSS, and JavaScript.

## 📋 Project Overview

This is a fully responsive portfolio website with 4 main pages connected through navigation. The site showcases a professional portfolio with skills, projects, and contact information.

## 🏗️ Project Structure

```
portfolio/
├── index.html          # Home page with hero section and features
├── about.html          # About section with skills and experience timeline
├── projects.html       # Portfolio projects showcase with filtering
├── contact.html        # Contact form and information
├── styles.css          # Complete styling with responsive design
├── script.js           # Interactive features and form handling
└── README.md           # This file
```

## 📄 Pages Description

### 1. **Home (index.html)**
- Hero section with introduction
- Call-to-action buttons
- Features section highlighting services
- Navigation to other pages

### 2. **About (about.html)**
- Professional biography
- Skills showcase with progress bars
- Skills organized by category (Frontend, Design, Tools)
- Experience timeline

### 3. **Projects (projects.html)**
- Grid layout of portfolio projects
- Project filtering functionality (All, Web Design, Web App, Other)
- Project cards with descriptions, tags, and links
- Call-to-action section

### 4. **Contact (contact.html)**
- Contact information cards
- Functional contact form
- Social media links
- Quick links to other pages

## 🔧 How to Use

1. **Open the website**: Open `index.html` in a web browser
2. **Navigate**: Use the navigation menu to browse different pages
3. **View Projects**: Filter projects by category on the Projects page
4. **Contact**: Fill out the contact form to send a message
5. **Customize**: Edit the HTML content to add your personal information

## 📝 Customization Guide

### Update Personal Information
- Change "MyPortfolio" to your name in the logo
- Update about section with your bio
- Add your real projects with descriptions
- Update contact information with your details
- Change social media links

### Modify Colors
Edit the CSS variables in `styles.css`:
```css
--primary-color: #2563eb;
--secondary-color: #10b981;
--text-dark: #1e293b;
```

### Add Images
Replace placeholder divs with actual image tags:
```html
<img src="your-image.jpg" alt="Description">
```
